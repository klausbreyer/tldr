Name: tldr
Short description: Summarize web pages and YouTube videos beside the page. One sentence and a few points, in English or German.

Description:
Get the main claims of a web page or YouTube video without leaving the source.

Click the tldr toolbar icon to summarize the current page, or right-click a link and choose "Summarize with tldr". The summary opens in Chrome’s side panel beside the original page.

Each summary contains one sentence and three to six short points. Switch between English and German, and copy a summary when you need it.

No account is required. The extension does not keep a history. Only the address you choose is sent to tldr.tf. The service fetches public web pages and uses Google Gemini through OpenRouter to create summaries. Private pages that require your browser login cannot be read. AI summaries can contain mistakes.

Website: https://tldr.tf
Privacy policy: https://tldr.tf/privacy
Single purpose: Summarize a user-selected web page or YouTube video in Chrome’s side panel.

Permission explanations:
activeTab: Read the address of the current tab only after the user clicks the extension icon.
contextMenus: Add a link menu action that summarizes the selected link.
sidePanel: Show the summary next to the original page.
https://tldr.tf/*: Embed the tldr service in the side panel.

Remote content: The side panel embeds https://tldr.tf in an iframe. Extension code is bundled in the package. The hosted application creates and displays the summary and does not call extension APIs.

Data disclosures: user-selected web addresses are transmitted to tldr.tf to perform the requested summary. Source text or video addresses are passed through OpenRouter to Google Gemini. No advertising, sale of data, or unrelated tracking.
